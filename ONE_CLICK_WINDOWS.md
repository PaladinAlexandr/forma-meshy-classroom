# Запуск FORMA одним файлом на Windows

1. Установленный Docker Desktop должен работать с **Linux containers**. Сам Docker скрипт не устанавливает; если движок остановлен, попытается запустить Docker Desktop и подождёт его готовности.
2. Распакуйте актуальный ZIP проекта целиком. Не запускайте файлы внутри нераспакованного архива.
3. В папке `meshy-classroom` дважды нажмите **START-FORMA.cmd**.

Скрипт сам:

- найдёт локальный IP компьютера или предложит выбрать сеть, если их несколько;
- создаст `.env.classroom` со случайными секретами при первом запуске;
- сохранит существующие пароли, ключ, базу и модели при повторном запуске;
- соберёт и запустит PostgreSQL, Redis, приложение, worker, beat и HTTPS-прокси;
- предложит создать администратора, если его ещё нет;
- запросит API-ключ Meshy скрытым вводом, если реальная генерация ещё не подключена; Enter без ключа оставит учебный режим;
- запросит через стандартное окно Windows права для настройки сети и брандмауэра;
- установит доверие к локальному HTTPS-сертификату для текущего пользователя;
- создаст **FORMA-student-access.zip** для подключения ученических компьютеров;
- проверит HTTPS-страницу состояния и откроет приложение в браузере.

При запросе Windows разрешите настройку сети, если выбрана доверенная сеть центра. Для этой сети выставляется профиль Private (доменная сеть остаётся доменной), доступ к TCP 8443 разрешается из локальной подсети. Если запрос отклонён или организация запрещает изменение правил, приложение сохранится и запустится, но сетевой доступ потребует администратора; скрипт сообщит об этом.

Пароль администратора задаётся в интерактивной команде Django и не показывается при вводе. После запуска войдите с ним в открывшейся странице. Существующий администратор повторно не создаётся и его пароль не меняется.

## Ученики

Передайте ученикам созданный **FORMA-student-access.zip**. На каждом компьютере его нужно распаковать и запустить **CONNECT-STUDENT.cmd** под Windows-пользователем ученика. Файл установит доверие к сертификату центра и откроет нужный адрес.

В ученическом архиве только публичный сертификат, адрес и скрипт подключения. API-ключ, пароль PostgreSQL и исходники сервера туда не включаются. Docker на ученических компьютерах не требуется. Ученические логины создайте в кабинете преподавателя на странице «Ученики».

## Повторный запуск

Запускайте **START-FORMA.cmd** снова. Он использует ту же конфигурацию и данные. В режиме live с уже заданным ключом он не запрашивает ключ повторно. Если в demo остаются незавершённые генерации, смена режима откладывается до их завершения — повторите запуск позже.

Если сервер сменил IP, скрипт обновит адрес в настройках и пересоздаст пакет подключения. Раздайте ученикам новый пакет. Желательно закрепить IP сервера на роутере.

## Если что-то не получилось

Окно остаётся открытым и показывает причину. Исправьте указанную проблему и запустите файл снова: скрипт не удаляет базу или volumes.

Первый запуск требует интернета и может занять несколько минут. Docker Desktop, Windows или корпоративная политика могут потребовать ручных действий: включения Linux engine, первоначальной настройки Docker или подтверждения прав администратора. Скрипт не принимает лицензионные соглашения и не вводит системные пароли за пользователя.

Для проверки без запуска и изменения конфигурации:

```powershell
.\START-FORMA.cmd -CheckOnly
```

Для подробных ручных шагов и резервного копирования см. `START_HERE_WINDOWS.md`.

Проверено: Windows PowerShell 5.1, синтаксис скриптов, сохранение и обновление конфигурации, генерация секретов, диагностическая команда приложения и режим CheckOnly. Полный первый запуск с Docker, UAC и установкой сертификата нужно проверить на целевом компьютере: Docker-служба на машине разработки не запущена.
