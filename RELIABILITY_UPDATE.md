# Обновление: ответы Meshy, большие файлы и управление классом

## Принятая задача больше не требует ручного ID

Meshy возвращает `202 Accepted` при создании фоновой задачи. Ранее клиент FORMA
принимал только `200` и `201`: обычный успешный ответ ошибочно переводил заявку
в «Нужна проверка отправки». Теперь клиент принимает ответы `2xx` с корректным
ID в поле `result`. ID сохраняется до записи события в историю, чтобы сбой
журнала не терял принятую платную задачу.

Это исправление относится ко всем этапам: изображение, 3D, скелет и анимация.
Животные и предметы по-прежнему создаются без анимаций, как выбрал преподаватель.

Для старых заявок без сохранённого ID откройте проект → **Сверка с Meshy →
Найти задачу в Meshy**. Список загружается через GET API внутри FORMA. Выберите
задачу по этапу и времени, подтвердите соответствие проекту. Приложение продолжит
проверку существующей генерации, без повторной платной отправки. Доступны страницы
по 50 задач, уже привязанные к другим проектам задачи не предлагаются.

Приложение не угадывает соответствие по одному лишь времени: в общем аккаунте
могут одновременно работать разные ученики и другие приложения. Для настоящего
таймаута, потери ответа или ответа без ID сверка остаётся необходимой. Если после
проверки задачи точно нет, преподаватель может подтвердить отсутствие в прежней
форме сверки. Платный POST автоматически не повторяется.

Источники: [статусы Meshy](https://docs.meshy.ai/en/api/errors),
[список задач анимации](https://docs.meshy.ai/en/api/animation#list-animation-tasks).

## Большие и недоступные файлы

- Фото ученика: до 10 МБ, до 20 мегапикселей. Проверяется до создания заявки.
- Сохраняемый FBX/GLB: до 250 МБ на файл. Проверяются Content-Length и реальный
  объём потока; слишком большой файл не сохраняется частично.
- Текстура: до 32 МБ и 20 мегапикселей.
- Однозначные ошибки отправки (`4xx`, включая `413`) завершают заявку ошибкой,
  показывают HTTP-код и краткое сообщение Meshy. Ключи и подписанные URL скрываются.
- Превышение лимита сохранения завершает заявку ошибкой и освобождает ученика.
  Загрузка такого же файла не повторяется бесконечно. Готовая задача/файл, который
  уже удалён или истёк, также не блокирует аккаунт бесконечными проверками сохранения.
- Временные ошибки сохранения повторяются с задержкой. После восьми неудачных
  проверок сохранение завершается ошибкой. Повторных генераций при этом нет.
- Преподаватель может нажать **Завершить обработку** у зависшей заявки.

Если файл FBX и GLB уже сохранены, а дальнейшая упаковка не удалась, отдельные
файлы остаются доступны на странице проекта. ZIP появляется, только если создан.

## Ученики и заявки

В разделе **Ученики** появились кнопки **Редактировать** и **Удалить**.
Редактируются имя, логин, доступ ко входу и новый пароль. Пустой новый пароль
сохраняет прежний. Повысить права ученика или изменить преподавателя через эту
форму нельзя. Удаление убирает ученика из списка, отключает вход и делает пароль
непригодным для входа, сохраняя историю его работ у преподавателя. Новые этапы
его заявок закрываются; уже отправленные задачи отслеживаются до завершения.

На странице проекта есть **Удалить заявку**. После подтверждения заявка попадает
в **Корзину** преподавателя и исчезает из кабинета ученика. Файлы и история
сохраняются; из корзины можно восстановить заявку без новой генерации.

Заявки до отправки закрываются сразу. Если задача уже отправлена в Meshy,
закрытие/удаление не означает остановку удалённой генерации: FORMA отслеживает её
до финального статуса и не запускает следующие платные этапы. До завершения
сохраняются место в общем лимите и блокировка новой генерации этого ученика.
Неизвестную отправку нужно сначала сверить. Это сохраняет ограничения одного
незавершённого проекта на ученика и максимум десяти активных задач центра.

## Установить обновление

Сделайте резервную копию по GITHUB_SETUP.md. В папке действующего проекта:

```powershell
.\forma-http.cmd stop
git pull --ff-only
.\START-FORMA-HTTP.cmd
```

Установщик применит миграцию `0007` и пересоберёт приложение. Затем Ctrl+F5 в
браузере. Файл `.env.classroom`, API-ключ, аккаунты и Docker volumes сохраняются.
Для заявок, застрявших на больших файлах, новый worker применит исправленную
обработку; преподаватель также может завершить сохранение вручную.

Если Meshy ещё генерирует модель, обновление не отправляет её повторно: очередь
восстанавливается по базе. Прерванные отправки без подтверждённого ID требуют
сверки, а не повторной отправки. При установке из ZIP замените исходные файлы
архивом обновления в существующей папке и запустите START-FORMA-HTTP.cmd.
