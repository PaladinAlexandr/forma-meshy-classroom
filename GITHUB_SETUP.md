# Сборка и запуск из GitHub

Репозиторий: https://github.com/PaladinAlexandr/forma-meshy-classroom

## Новый Windows-компьютер

1. Установите Git for Windows и Docker Desktop, включите Linux containers и завершите первоначальную настройку Docker. Python, PostgreSQL и Redis вручную устанавливать не нужно.
2. В PowerShell перейдите в папку для проекта и выполните:

```powershell
git clone https://github.com/PaladinAlexandr/forma-meshy-classroom.git
cd forma-meshy-classroom
.\START-FORMA-HTTP.cmd
```

3. При первом запуске выберите сеть центра, если скрипт предложит несколько вариантов. Создайте администратора. Введите API-ключ Meshy в скрытом поле или нажмите Enter для демо. Подтвердите запрос Windows на настройку локального сетевого доступа.
4. Дождитесь сообщения об успешном запуске. Откройте показанный URL, например http://192.168.1.50:8010. Ученики в той же сети открывают этот адрес в браузере. Для них не нужны Docker, сертификаты и архив подключения.
5. Войдите администратором в приложение и создайте аккаунты учеников. Страница /admin/ предназначена для администрирования Django.

Можно обойтись без Git: на GitHub нажмите Code → Download ZIP, распакуйте архив целиком и запустите START-FORMA-HTTP.cmd. Для дальнейшего обновления через git pull предпочтительно клонирование.

## Обновление установленного приложения

Дождитесь завершения генераций. Сделайте резервную копию PostgreSQL и media по START_HERE_WINDOWS.md. В папке клонированного проекта:

```powershell
.\forma-http.cmd stop
git pull --ff-only
.\START-FORMA-HTTP.cmd
```

Скрипт пересоберёт образы и применит миграции. Если Git сообщил о конфликте локальных правок, сохраните эти правки и разберите конфликт; не используйте reset --hard для обычного обновления. Не удаляйте тома Docker и не выполняйте down -v.

## Где хранятся ключи и данные

Настройки и API-ключ — только в .env.classroom на сервере. База, фотографии и модели — в локальных томах Docker. Эти данные не публикуются в GitHub. На новом компьютере после клонирования будет новая установка: старые аккаунты и модели переносятся только восстановлением резервной копии. Адрес сервера и пароль БД не нужно копировать на ученические компьютеры.

GitHub хранит опубликованный исходный код. Команда git pull получает уже опубликованные обновления; новые изменения ещё нужно коммитить и отправлять в репозиторий.

## Что входит в проект

Фото или текстовый промпт → проверка преподавателя → генерация через общий API Meshy. Для текстовой идеи: картинка → выбор ученика → отдельное разрешение преподавателя на 3D. До 10 активных задач и один незавершённый проект на ученика. Результат: FBX и ZIP с доступными PBR-текстурами и инструкцией для Unity 6 URP.

Подробности: README.md, TEXT_TO_IMAGE_UPDATE.md, VERIFICATION.md. Тесты запускаются GitHub Actions с PostgreSQL и Redis, без реальных платных запросов Meshy.
