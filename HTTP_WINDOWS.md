# Локальный запуск без сертификата

Дважды нажмите START-FORMA-HTTP.cmd. Установщик использует существующий .env.classroom, аккаунты, базу, фотографии и модели. HTTPS-режим этого проекта заменяется HTTP-режимом, одновременно их запускать не нужно.

Адрес: http://IP-СЕРВЕРА:8010 (например http://192.168.1.50:8010).
Ученики открывают этот адрес; сертификат и FORMA-student-access.zip не нужны. Откройте новый HTTP-адрес и войдите заново, если ранее использовали HTTPS.

HTTP не шифрует пароли и фотографии. Используйте в доверенной локальной сети центра, без проброса порта в интернет. Подключение сервера к API Meshy остаётся HTTPS.

Для команд обслуживания используйте forma-http.cmd, например .\forma-http.cmd logs --tail=60 proxy web или .\forma-http.cmd stop. Для возврата HTTPS запустите START-FORMA.cmd.

При установке обновления распакуйте файлы поверх существующего проекта с заменой. Не удаляйте .env.classroom и тома Docker. При активных генерациях дождитесь их завершения перед переключением режима.

HTTP-порт 8010 публикуется напрямую сервисом web (порт контейнера 8000). Прокси Caddy в этом режиме остановлен и не используется.
