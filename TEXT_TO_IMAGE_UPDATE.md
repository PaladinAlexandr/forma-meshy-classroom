# Промпт → изображение → 3D

## Установка на существующий Windows-сервер

1. Дождитесь завершения активных генераций. Сделайте обычную резервную копию базы и media по START_HERE_WINDOWS.md.
2. В папке проекта остановите приложение: .\forma-http.cmd stop.
3. Распакуйте FORMA-text-to-image-update.zip прямо в папку, содержащую START-FORMA-HTTP.cmd, с заменой файлов. Архив имеет файлы сразу в корне, без дополнительной папки.
4. Запустите START-FORMA-HTTP.cmd. Скрипт пересоберёт приложение и автоматически применит миграцию 0005. Старые аккаунты, ключ и файлы сохраняются.
5. После запуска обновите страницу в браузере Ctrl+F5.

## Для ученика

В новом проекте выбери «С чего начнём?»: загрузить фото или описать идею. Введи промпт до 800 символов, можно по-русски, и выбери стиль текстуры. После одобрения промпта преподавателем появится картинка. Нажми «Хочу 3D по этой картинке» либо «Завершить без 3D». При выборе 3D преподаватель должен отдельно одобрить картинку. После завершения доступны FBX и ZIP с текстурами для Unity 6 URP.

Если загружаешь своё фото, промпт необязателен: он задаёт текстуру и цвета вместо шаблона стиля, геометрию задаёт фото. Отдельная заметка преподавателю в Meshy не отправляется.

## Для преподавателя

Первое одобрение текстовой идеи разрешает только картинку, второе — 3D с текстурами. Каждое создаёт отдельную задачу Meshy и расходует кредиты. Неодобренные запросы не отправляются. Модель картинок по умолчанию nano-banana; можно задать MESHY_IMAGE_MODEL в .env.classroom без смены ключа.

Общая очередь ограничена 10 активными задачами на оба типа генерации. Пока ученик выбирает картинку, слот общего аккаунта освобождён, но новая заявка ученику запрещена. В случае отказа от картинки можно подать новую заявку с учётом дневного лимита. Месячный лимит считает проекты при первом одобрении, а не число отдельных API-операций; расходы отображаются отдельно и суммой после завершения.

Таймаут при создании любой задачи не вызывает автоматический повтор POST. Преподаватель сверяет соответствующий тип задачи в Meshy и привязывает существующий ID. Локально сохранённая картинка не зависит от срока действия ссылки Meshy.

В режиме demo вместо настоящей генерации показывается явно подписанный учебный кристалл. API-контракт сверён с https://docs.meshy.ai/en/api/text-to-image ; реальные платные вызовы в этой среде не выполнялись.
